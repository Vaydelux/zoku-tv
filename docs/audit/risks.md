# Zoku TV — Technical, Security, UX, and Operational Risk Register

| ID | Category | Severity | Description | Affected Files | Mitigation Plan |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **RISK-01** | Security / Child Safety | **Critical** | Kids Mode filters by `vote_average < 7.5` instead of age classification/genre safety, exposing mature R/TV-MA content to Kids profiles and hiding high-rated family films. | `app/discover/page.tsx`, `app/search/page.tsx`, `app/genre/[id]/page.tsx`, `app/title/[type]/[id]/page.tsx`, `app/home/page.tsx`, `app/anime/[id]/page.tsx`, `app/watch/*` | Create `lib/kids-mode.ts` with explicit safe/restricted genre rules, certification checks, and title/keyword heuristics for TMDB & AniList; enforce across all browse, search, detail, and watch routes. |
| **RISK-02** | Security / Auth | **High** | Local fallback authentication stores user passwords in plaintext in `localStorage` (`zoku_registered_users`). | `lib/firebase.ts` | Replace plaintext password storage with salted SHA-256 / Web Crypto digest verification (`passwordHash` + `salt`) and auto-migrate any legacy local entries without storing plaintext. |
| **RISK-03** | Data Integrity | **High** | First-time playback never enables `usePlayerProgressListener` because `playbackStarted` defaults to `urlStartAt > 0` (`false`). | `hooks/useWatchProgress.ts` | Enable playback progress listener immediately when `!canResume` (`!showResumePrompt`) so first-time viewers have their progress recorded. |
| **RISK-04** | State Synchronization | **High** | `listenToOrderedCollection` in `lib/firebase.ts` registers listener keys with `?orderBy=...`, which `triggerDbChange(path)` never notifies in local mode. | `lib/firebase.ts` | Update `triggerDbChange` to notify all listener keys matching `parentPath` or starting with `${parentPath}?orderBy=`. |
| **RISK-05** | Privacy / Caching | **High** | Service worker (`public/sw.js`) caches all HTTP 200 GET responses regardless of origin, risking caching cross-origin embed urls or Firebase responses. | `public/sw.js` | Restrict SW runtime caching to same-origin static assets/navigation and explicit public poster CDNs (`image.tmdb.org`, `s4.anilist.co`), bumping cache version and evicting stale caches. |
| **RISK-06** | Privacy / Data Lifecycle | **Medium** | Deleting a profile leaves behind its subcollections (`watchlist`, `continueWatching`, `watchHistory`, `episodeProgress`) and `localStorage` search history. | `stores/index.ts` | Update `deleteProfile` to enumerate and remove all subcollection documents and profile-scoped `localStorage` keys before deleting the profile document. |
| **RISK-07** | Build / Type Safety | **High** | `motion/react` import fails `tsc --noEmit` (`TS7016`) and `next build` webpack bundling (`visual-element-target.mjs`), and `next/font/google` fails offline builds. | `AnimeRail.tsx`, `ContinueWatchingRail.tsx`, `HeroCarousel.tsx`, `TitleRail.tsx`, `WatchHistoryRail.tsx`, `app/layout.tsx`, `tsconfig.json` | Switch `motion/react` imports to `"framer-motion"`, fix `tsconfig.json` type resolution, and configure resilient CSS font stacks in `app/layout.tsx` so offline and online builds succeed. |
| **RISK-08** | Third-Party Player Dependency | **Operational** | External embed providers (`vidlink`, `vidsrc`, `2embed`, `filmu`, etc.) are third-party cross-origin iframes that may experience downtime, ads, or silent stream failure. | `app/watch/*`, `components/watch/ServerSelect.tsx` | Preserve all provider URLs untouched; provide clear "Container Ready" vs. "Playback Synced" status, one-click "Switch Next Server" & "Retry" controls, and Strict vs. Compatibility sandbox toggles. |
